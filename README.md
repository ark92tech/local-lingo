# Local Lingo · UK

UK regional words, old and new, on a map — with "sounds like" spellings, regional voices and a quiz.

- `words.json` holds every word: `w` word, `m` meaning, `p` sounds-like spelling, `s` source key (see `sources` at the top).
- Edit `words.json` here on GitHub and Vercel redeploys automatically.
- Readers report problems via GitHub Issues ("Not quite right? Report" on each card).
